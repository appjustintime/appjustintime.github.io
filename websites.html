위 미리보기는 예시 자료로 보입니다. 실제 웹은 손님 앱과 같은 서버의 자료를 읽습니다.

앱과 같은 서버로 연동

  • 앱 공지·게시판에 올린 글이 웹에 바로 보입니다.
  • 앱 카드 목록(메뉴·상품)이 웹 메뉴가 됩니다.
  • 앱 예약 달력의 빈 시간이 웹에 보입니다(예약은 앱에서).
  • 웹 문의 양식으로 들어온 글은 관리자 화면에 쌓입니다.

서버 없이 웹만 만들 수도 있습니다. 그때는 글로 적은 메뉴와 메일 문의로 돕니다.

웹 기능 값

웹페이지 연동 15만 원부터에 대문·소개가 들어 있고, 아래 칸을 더합니다.

대문로고·이름·한 줄 소개·바로가기 단추기본 포함
소개우리 이야기 글·사진기본 포함
메뉴·상품카드 목록 — 앱 카드 목록이 있으면 같은 서버 자료, 없으면 글로 적은 목록+2만 원
위치 지도지도 + 카카오맵·네이버 지도 길찾기, 영업시간+2만 원
문의 양식이름·연락처·내용 → 관리자 웹에 쌓임(서버 없으면 메일 쓰기)+2만 원서버 판은 월 관리비
공지앱 공지 배너·게시판 공지를 웹에도(읽기만)+2만 원
게시판 새 글앱 게시판 새 글 목록(읽기만, 쓰기는 앱에서)+4만 원
예약 빈칸앞으로 며칠 예약 가능한 칸(신청은 앱에서)+4만 원
앱 내려받기 단추구글 플레이·앱 스토어 단추0원
